@AGENTS.md

This project is AdminKu - WhatsApp Admin Toolkit for Indonesian online sellers.

Quick reference:
- **Tech**: Next.js 16, React 19, Tailwind CSS v4, NextAuth v5, localStorage
- **Routes**: `/` landing, `/login` auth, `/pricing` plans, `/app/*` dashboard
- **Features**:
  - Core: Message formatter, quotation/invoice generator, order recap, payment reminder, shipping confirmation
  - Data: Customer database, template library, document history, usage stats
  - UI: Dark mode, bottom nav, toast notifications, PDF export, WhatsApp share
- **Auth**: Google OAuth via NextAuth v5, middleware protects `/app` routes

See AGENTS.md for full product context, strategy, and roadmap.
